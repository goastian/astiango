# Sempre respeitaremos sua privacidade.

Acreditamos que a privacidade deve ser um direito fundamental. Ao usar o AstianGO, você pode ter certeza de que fazemos tudo
possível manter suas informações privadas como deveriam ser - privadas.
Fazemos isso principalmente simplesmente não armazenando nenhuma informação privada sua.
Isso simplifica as coisas, tanto para você quanto para nós.

Aqui está uma breve visão geral da sua privacidade:

- Não armazenamos seu endereço IP.
- Não armazenamos nenhuma informação que possa ser usada para imprimir impressões digitais em seu dispositivo, navegador, etc.
- Não compartilhamos nenhum dado do usuário com terceiros.
- Recolhemos apenas os dados necessários à prestação e melhoria do serviço.
- Servimos todo o conteúdo diretamente de nossos servidores para evitar rastreamento por terceiros.
- Usamos criptografia HTTPS em todos os lugares.

Por padrão, armazenamos algumas estatísticas de uso para melhorar a pesquisa
resultados. Especificamente, as seguintes informações são armazenadas para cada pesquisa:

- O texto utilizado para realizar a pesquisa.
- A lista de URLs retornados para a pesquisa.
- Se algum dos resultados foi clicado ou não e, em caso afirmativo, qual.
- Um ID gerado automaticamente e exclusivo para cada nova pesquisa.
- Um carimbo de data/hora arredondado para a hora mais próxima.

Esses dados são usados exclusivamente para treinar nossos modelos de classificação, o que melhora a pesquisa
resultados para todos. Fazemos todo o possível para não armazenar nada que possa amarrar
suas pesquisas de volta para você ou até mesmo descobrir quais pesquisas foram realizadas por
o mesmo indivíduo. Esperamos que você confie em nós esses dados limitados, pois eles nos ajudam
melhorar tremendamente nossos serviços. Você pode cancelar isso a qualquer momento no
[página de configurações](/settings/privacy) e não armazenaremos nada.

Você não precisa acreditar em nossa palavra sobre essas afirmações, pois é nossa
[o código-fonte está disponível para todos.](https://github.com/goastian/astiango)

## Recursos do navegador

A maior parte do site deve funcionar com apenas um conjunto mínimo de recursos do navegador ativados. Usamos javascript e alguns outros recursos do navegador para, opcionalmente, melhorar a experiência do usuário em alguns lugares. Tentamos fornecer uma visão geral aqui para que você possa ativar opcionalmente os recursos e funcionalidades que deseja usar.

- [LocalStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) é usado para armazenar sua óptica e todas as outras configurações. As preferências que influenciam os resultados da pesquisa, por ex. sites gostados/não gostados/bloqueados, são enviados para o backend nos parâmetros de solicitação GET da sua pesquisa.
- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) é usado em vários lugares, mas nos esforçamos para usá-lo exclusivamente para melhorar a experiência do usuário. Você deve ser capaz de realizar pesquisas e encontrar sites semelhantes em 'explorar' sem o javascript habilitado. Por favor [envie um relatório de bug](https://github.com/goastian/astiango/issues/new) se este não for o caso para que possamos investigar. No entanto, o Javascript é necessário para fornecer funcionalidades como alterar suas configurações, gostar/não gostar de sites, gerenciar a ótica, remover facilmente um único site em 'explorar' etc.
- [SSE](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events) são usados para transmitir o resumo de volta ao seu navegador quando você solicita o resumo de um resultado de pesquisa.

Não usamos cookies primários e, especialmente, de terceiros.
