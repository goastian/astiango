# 我们将永远尊重您的隐私。

我们认为隐私应该是一项基本权利。使用AstianGO，您尽可放心，我们为您做到一切
可以按照应有的方式保护您的私人信息 - 私密。
我们主要通过根本不存储您的任何私人信息来做到这一点。
这对您和我们来说都让事情变得简单。

以下是您的隐私的简要概述：

- 我们不存储您的 IP 地址。
- 我们不会存储任何可用于对您的设备、浏览器等进行指纹识别的信息。
- 我们不与任何第三方共享任何用户数据。
- 我们仅收集提供和改进服务所需的数据。
- 我们直接从我们的服务器提供所有内容，以防止第三方跟踪。
- 我们在任何地方都使用 HTTPS 加密。

默认情况下，我们确实存储一些使用统计信息以改进搜索
结果。具体来说，每次搜索都会存储以下信息：

- 用于执行搜索的文本。
- 搜索返回的 url 列表。
- 是否点击了任何结果，如果点击了，是哪一个。
- 每个新搜索自动生成且唯一的 ID。
- 时间戳四舍五入到最接近的小时。

该数据仅用于训练我们的排名模型，从而改善搜索
为每个人带来结果。我们竭尽全力不存放任何可以打结的东西
您的搜索返回给您，甚至找出哪些搜索是由
同一个人。我们希望您信任我们这些有限的数据，因为它对我们有帮助
极大地改善我们的服务。您可以随时从
[设置页面](/settings/privacy)，我们根本不会存储任何内容。

您不必将我们对这些主张的承诺视为我们的主张
[源码公开给大家。](https://github.com/goastian/astiango)

## 浏览器功能

大多数网站应该只在启用最少的浏览器功能的情况下运行。我们使用 JavaScript 和其他一些浏览器功能来选择性地增强某些地方的用户体验。我们尝试在此处提供概述，以便您可以选择启用您想要使用的特性和功能。

- [LocalStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) 用于存储您的光学器件和所有其他设置。影响搜索结果的偏好，例如喜欢/不喜欢/阻止的网站，在搜索的 GET 请求参数中发送到后端。
- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) 在许多地方使用，但我们努力仅使用它来增强用户体验。您应该能够在不启用 JavaScript 的情况下执行搜索并在“探索”中找到类似的网站。如果情况并非如此，请[提交错误报告](https://github.com/goastian/astiango/issues/new)，以便我们进行调查。然而，Javascript 需要提供诸如更改设置、喜欢/不喜欢网站、管理光学、轻松删除“探索”中的单个网站等功能。
- [SSE](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events) 用于在您请求汇总搜索结果时将摘要流式传输回您的浏览器。

我们不使用任何第一方（尤其是第三方）cookie。
