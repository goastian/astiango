# Siempre respetaremos tu privacidad.

Creemos que la privacidad debería ser un derecho fundamental. Al utilizar AstianGO, puede estar seguro de que hacemos todo
Es posible mantener su información privada como se supone que debe ser: privada.
Principalmente hacemos esto simplemente no almacenando ninguna información privada suya.
Esto simplifica las cosas, tanto para usted como para nosotros.

Aquí hay una breve descripción general de su privacidad:

- No almacenamos su dirección IP.
- No almacenamos ninguna información que pueda usarse para tomar huellas digitales de su dispositivo, navegador, etc.
- No compartimos ningún dato del usuario con terceros.
- Recopilamos únicamente los datos necesarios para proporcionar y mejorar el servicio.
- Servimos todo el contenido directamente desde nuestros servidores para evitar el seguimiento por parte de terceros.
- Usamos cifrado HTTPS en todas partes.

De forma predeterminada, almacenamos algunas estadísticas de uso para mejorar la búsqueda.
resultados. En concreto se almacena la siguiente información para cada búsqueda:

- El texto utilizado para realizar la búsqueda.
- La lista de URL devueltas por la búsqueda.
- Si se hizo clic o no en alguno de los resultados y, de ser así, en cuál.
- Una identificación que se genera automáticamente y es única para cada nueva búsqueda.
- Una marca de tiempo redondeada a la hora más cercana.

Estos datos se utilizan únicamente para entrenar nuestros modelos de clasificación, lo que mejora la búsqueda.
resultados para todos. Hacemos todo lo posible para no almacenar nada que pueda atar
sus búsquedas o incluso averiguar qué búsquedas fueron realizadas por
el mismo individuo. Esperamos que nos confíe estos datos limitados, ya que nos ayudarán.
mejorar enormemente nuestros servicios. Puede optar por no participar en cualquier momento desde el
[página de configuración](/settings/privacy) y no almacenaremos nada en absoluto.

No es necesario que tome nuestra palabra para estas afirmaciones como nuestra
[el código fuente está disponible para todos.](https://github.com/goastian/astiango)

## Funciones del navegador

La mayor parte del sitio debería funcionar con sólo un conjunto mínimo de funciones del navegador habilitadas. Usamos javascript y algunas otras funciones del navegador para mejorar opcionalmente la experiencia del usuario en algunos lugares. Intentamos proporcionar una descripción general aquí para que, opcionalmente, pueda habilitar las características y funcionalidades que desea utilizar.

- [Almacenamiento local](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) se utiliza para almacenar su óptica y todas las demás configuraciones. Las preferencias que influyen en los resultados de la búsqueda, p.e. Sitios que me gustan/no me gustan/bloqueados, se envía al backend en los parámetros de solicitud GET de su búsqueda.
- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) se utiliza en varios lugares, pero nos esforzamos por utilizarlo únicamente para mejorar la experiencia del usuario. Debería poder realizar búsquedas y encontrar sitios similares en 'explorar' sin JavaScript habilitado. Por favor [envíe un informe de error](https://github.com/goastian/astiango/issues/new) si este no es el caso para que podamos investigarlo. Sin embargo, se necesita Javascript para proporcionar funciones como cambiar la configuración, dar me gusta o no a los sitios, administrar la óptica, eliminar fácilmente un solo sitio en 'explorar', etc.
- [SSE](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events) se utilizan para transmitir el resumen a su navegador cuando solicita resumir un resultado de búsqueda.

No utilizamos cookies propias y, especialmente, de terceros.
