# Nous respecterons toujours votre vie privée.

Nous pensons que la vie privée devrait être un droit fondamental. Lorsque vous utilisez AstianGO, vous pouvez être assuré que nous faisons tout
possible de garder vos informations privées comme elles sont censées l'être : privées.
Nous le faisons principalement en ne stockant aucune de vos informations privées.
Cela simplifie les choses, tant pour vous que pour nous.

Voici un bref aperçu de votre vie privée :

- Nous ne stockons pas votre adresse IP.
- Nous ne stockons aucune information pouvant être utilisée pour empreinte digitale sur votre appareil, votre navigateur, etc.
- Nous ne partageons aucune donnée utilisateur avec des tiers.
- Nous collectons uniquement les données nécessaires à la fourniture et à l'amélioration du service.
- Nous diffusons tout le contenu directement depuis nos serveurs pour empêcher le suivi par des tiers.
- Nous utilisons le cryptage HTTPS partout.

Par défaut, nous stockons certaines statistiques d'utilisation afin d'améliorer la recherche
résultats. Plus précisément, les informations suivantes sont stockées pour chaque recherche :

- Le texte utilisé pour effectuer la recherche.
- La liste des URL renvoyées pour la recherche.
- Si l'un des résultats a été cliqué ou non et si oui, lequel.
- Un identifiant généré automatiquement et unique à chaque nouvelle recherche.
- Un horodatage arrondi à l'heure inférieure.

Ces données sont uniquement utilisées pour entraîner nos modèles de classement, ce qui améliore la recherche.
des résultats pour tout le monde. Nous faisons de grands efforts pour ne rien stocker qui puisse attacher
vos recherches vous renvoient ou même déterminer quelles recherches ont été effectuées par
le même individu. Nous espérons que vous nous confiez ces données limitées car elles nous aident
améliorer considérablement nos services. Vous pouvez vous désinscrire à tout moment depuis le
[page des paramètres](/settings/privacy) et nous ne stockerons rien du tout.

Vous n'êtes pas obligé de nous croire sur parole pour ces affirmations, car notre
[le code source est accessible à tous.](https://github.com/goastian/astiango)

## Fonctionnalités du navigateur

La majeure partie du site devrait fonctionner avec seulement un ensemble minimal de fonctionnalités de navigateur activées. Nous utilisons Javascript et d'autres fonctionnalités du navigateur pour éventuellement améliorer l'expérience utilisateur à certains endroits. Nous essayons de fournir ici un aperçu afin que vous puissiez éventuellement activer les fonctionnalités que vous souhaitez utiliser.

- [LocalStorage](https://developer.mozilla.org/en-US/docs/Web/API/Window/localStorage) est utilisé pour stocker vos optiques et tous les autres paramètres. Les préférences qui influencent les résultats de recherche, par ex. les sites aimés/détestés/bloqués, sont envoyés au backend dans les paramètres de requête GET de votre recherche.
- [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript) est utilisé à plusieurs endroits, mais nous nous efforçons de l'utiliser uniquement pour améliorer l'expérience utilisateur. Vous devriez pouvoir effectuer des recherches et trouver des sites similaires dans « explorer » sans que javascript soit activé. Veuillez [soumettre un rapport de bug](https://github.com/goastian/astiango/issues/new) si ce n'est pas le cas afin que nous puissions l'examiner. Javascript est cependant nécessaire pour fournir des fonctionnalités telles que modifier vos paramètres, aimer/ne pas aimer les sites, gérer l'optique, supprimer facilement un seul site dans « explorer », etc.
- [SSE](https://developer.mozilla.org/en-US/docs/Web/API/Server-sent_events) sont utilisés pour renvoyer le résumé vers votre navigateur lorsque vous demandez de résumer un résultat de recherche.

Nous n’utilisons aucun cookie propriétaire, et surtout pas tiers.
