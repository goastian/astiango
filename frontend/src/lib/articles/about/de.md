# Über uns

AstianGO ist eine Open-Source-Suchmaschine, die der Benutzer sehen kann
genau, was vor sich geht, und passen Sie fast alles an ihrer Suche an
Ergebnisse. Es ist eine Suchmaschine, die genau für Hacker und Bastler gemacht ist
uns selbst. Keine Suchanfragen mehr, bei denen einige der Begriffe in der Abfrage nicht verwendet werden, und
Die Engine versucht zu erraten, was Sie _wirklich_ gemeint haben. Sie bekommen, wonach Sie suchen.

## Unsere Werte

- _Vollständige Transparenz_ -- Sie können unseren Code einsehen und die Entwicklung verfolgen
  direkt auf [Github](https://github.com/goastian/astiango)
- _Privatsphäre im Fokus_ -- Wir werden Sie niemals verfolgen. Zeitraum. Und das kannst du immer
  Überprüfen Sie dies in unserem [Quellcode.](https://github.com/goastian/astiango)
- _Immens anpassbar_ – Unser Ziel ist es, Ihnen die Möglichkeit zur Anpassung zu geben
  alles rund um die Suche. Sie können Websites blockieren, Websites verstärken und Prioritäten setzen
  Links von bestimmten Websites und vieles mehr.

Oh, und wenn wir jemals böse werden (vielleicht indem wir unser Motto ändern), nehmen Sie bitte unser
Code und starten Sie einen Konkurrenten. Die Tatsache, dass Sie über diese Fähigkeit verfügen, wird dafür sorgen
dass unsere Werte immer mit unseren Nutzern übereinstimmen.
